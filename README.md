# Tic Tac Toe

Klassisches Tic-Tac-Toe für zwei Spieler im Browser.

## Funktionen

- Abwechselnd Kreis und Kreuz setzen (als animierte SVG-Symbole)
- Erkennung des Spielendes und der Gewinnkombination
- Gewinnlinie wird eingezeichnet
- Neustart per Button

## Technologien

HTML5 · CSS3 · JavaScript (ohne Framework)

## Projekt starten

1. Repository klonen: `git clone https://github.com/KonstantinFenzlein/Tic-Tac-Toe.git`
2. `index.html` im Browser öffnen – keine Installation nötig.
